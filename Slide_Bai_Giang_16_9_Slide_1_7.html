Slide 5 / 14

1. Tính đóng gói (Encapsulation)

Biến _registered là private. Bên ngoài chỉ có thể đọc thông qua getter List.unmodifiable(_registered), ngăn chặn việc UI tự ý chỉnh sửa danh sách.

2. Trạng thái dẫn xuất (Derived State)

totalCredits và status được tính tức thì từ danh sách bằng toán tử fold(). Đảm bảo nguyên tắc Single Source of Truth.

3. Ràng buộc tín chỉ & Notify có điều kiện

Tối thiểu 14 TC, tối đa 24 TC, chống trùng môn. Nếu có lỗi: trả về chuỗi String? và TUYỆT ĐỐI KHÔNG GỌI notifyListeners(), tránh rebuild thừa!

// lib/notifiers/registration_notifier.dart (rút gọn) class RegistrationNotifier extends ChangeNotifier { static const int minCredits = 14; static const int maxCredits = 24; final List<Course> _registered = []; List<Course> get registered => List.unmodifiable(_registered); int get totalCredits => _registered.fold( 0, (sum, course) => sum + course.credits); String? register(Course course) { if (isRegistered(course.id)) { return 'Đã đăng ký!'; } if (totalCredits + course.credits > maxCredits) { return 'Vượt quá giới hạn tối đa 24 tín chỉ!'; } _registered.add(course); notifyListeners(); // CHỈ THÔNG BÁO KHI STATE THẬT SỰ ĐỔI! return null; } }

Cách đọc State Hành vi Rebuild Cơ chế hoạt động Áp dụng trong dự án
context.watch<T>() Mỗi lần notifyListeners() Đăng ký widget làm subscriber toàn phần CreditBadge (AppBar), RegisteredScreen
<Consumer<T>> Chỉ chạy lại hàm builder Khoanh vùng rebuild; có tham số child giữ lại UI tĩnh SummaryBar (thanh tiến độ ở chân màn hình)
context.select<T, R>() CHỈ khi giá trị con R đổi Lọc điều kiện, bỏ qua các thay đổi khác trong Notifier CourseTile (chỉ theo dõi isRegistered(id))
context.read<T>() KHÔNG BAO GIỜ Lấy tham chiếu Notifier để gọi method, không đăng ký lắng nghe Các nút bấm onPressed: Đăng ký, Hủy môn, Clear
⭐ QUY TẮC VÀNG: watch / select / Consumer đặt trong hàm build(); context.read đặt trong callback sự kiện (onPressed)!
